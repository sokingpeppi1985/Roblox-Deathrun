# Roblox Deathrun

Deathrun-карта для Roblox в духе classic "Deathrun" из CS 1.6: один игрок —
Killer, управляет ловушками вручную; остальные — Runners, бегут через
5 секций к финишу, уворачиваясь от смертельных механизмов.

Вся карта строится процедурно из Lua-кода при старте сервера — геометрия,
ловушки и логика раунда версионируются как обычный код, без бинарного
файла Roblox Studio (`.rbxl`).

## Структура проекта (Rojo)

```
default.project.json      -- маппинг папок в Roblox-сервисы
src/
  shared/                 -> ReplicatedStorage
    Config.lua             -- тайминги и параметры всех ловушек
    Tags.lua                -- имена тегов CollectionService
    Remotes.lua              -- создаёт RemoteEvent'ы для Killer-GUI и HUD
  server/                 -> ServerScriptService
    init.server.lua          -- точка входа: строит карту, стартует раунд
    RoundManager.lua         -- команды Killer/Runners, таймер, победа/поражение
    KillerController.lua     -- проверяет права и кулдауны ручных ловушек
    MapBuilder/               -- процедурная генерация секций карты
      init.lua
      GroundUtil.lua          -- общие помощники: земля, kill-zone (пропасть/лава)
      Section1_Forest.lua      -- Секция 1: Лесная тропа
      Section2_Swamp.lua       -- Секция 2: Болото
      Section3_Cave.lua        -- Секция 3: Вход в пещеру
      Section4_Lava.lua        -- Секция 4: Лавовые пещеры
      Section5_Final.lua       -- Секция 5: Финальный рывок
      Finish.lua                -- Финишная арка (иммунитет к ловушкам)
    Traps/                    -- по одному модулю на ловушку
      Common.lua                -- общие хелперы (Humanoid, урон, кулдаун)
      FallingBridge.lua          -- 1.1 Проваливающийся мост
      SwingingLog.lua            -- 1.2 Маятник-бревно
      SinkingMounds.lua          -- 2.1 Тонущие кочки
      HiddenSpikes.lua           -- 2.2 Скрытые шипы в траве
      SlowingMud.lua             -- 2.3 Замедляющая жижа
      FallingStalactites.lua     -- 3.1 Падающие сталактиты
      SideSpikes.lua             -- 3.2 Узкий проход с боковыми шипами
      HeatingPlatforms.lua       -- 4.1 Раскаляющиеся платформы (переиспользуется в 5.1)
      FireGeysers.lua            -- 4.2 Огненные гейзеры (переиспользуется в 5.1)
      RamTrap.lua                -- 4.3 Ловушка-таран
      FinalTrapdoor.lua          -- 5.2 Финальная ручная ловушка (единственный инстакилл без предупреждения)
  client/                 -> StarterPlayer.StarterPlayerScripts
    KillerGui.client.lua    -- панель кнопок ловушек (видна только Killer'у)
    HUD.client.lua          -- статус раунда/таймер для всех игроков
```

## Как открыть в Roblox Studio

1. Установите [Rojo](https://rojo.space/) (плагин для Studio + CLI).
2. В корне репозитория выполните `rojo serve`.
3. В Studio подключитесь плагином Rojo к запущенному серверу и нажмите
   "Connect" — вся папка `Workspace.Map` будет собрана автоматически
   Lua-скриптом `init.server.lua` при запуске игры (F5 / Play Solo,
   а для полноценного теста раунда — Local Server с 2+ игроками).

## Игровой цикл

- `RoundManager.lua` ждёт минимум двух игроков, случайно назначает одного
  Killer'ом (команда `Killer`), остальных — `Runners`, телепортирует всех
  на старт и запускает таймер раунда (240 сек).
- Runners бегут к финишной арке (`Finish.lua`); наступление на `FinishLine`
  засчитывается через `RoundManager.PlayerFinished`.
- Killer видит отдельную GUI-панель (`KillerGui.client.lua`) с кнопками для
  ручных ловушек: маятник (1.2), скрытые шипы (2.2), боковые шипы (3.2),
  таран (4.3), финальный люк (5.2). Кнопки шлют `RemoteEvent` на сервер,
  где `KillerController.lua` проверяет, что отправитель — текущий Killer,
  раунд активен, и ловушка не на кулдауне.
- Победа Runners — если все добежали до финиша раньше, чем истечёт время
  или чем умрут все Runners; иначе побеждает Killer.

## Принцип "честности" (fairness)

Все ловушки, кроме одной, дают игроку видимый или звуковой сигнал до
срабатывания (потрескивание доски, дрожание земли, шорох травы, трещина в
потолке, изменение цвета плиты). Единственное исключение — финальный
трапдор (5.2) прямо перед финишем: он открывается мгновенно по нажатию
Killer'а без предупреждения, согласно правилу "не более одной такой
ловушки на карте".

Игроки внутри зоны финиша неуязвимы для всех ловушек: `Finish.lua` ставит
персонажу атрибут `InFinishZone`, который проверяет `Common.isProtected`
перед нанесением урона в каждом модуле ловушки.
